# yudeia_true_coin_value

**回収示唆**: 首吊り自殺の直後に現れるこの銀貨が、彼女の「死」を否定し、「再生（転生）」させるためのキーアイテムとなる。名前の力によって運命を書き換える展開へ。

> 偽名が刻印された贋金の数十倍の価値を持つであろうその銀貨には、『ユディーア』というまことの名が刻まれていた。（p461）
