# 観察ページ ch00434__4-203　夜アカシャ裂くキャスケット③.md

### セリアック＝ニア
- 何であるか: 物語の中心にいる少女。ドラトリアの姫君であり、聖なる姫としての宿命から逃れようとしている。猫のような軽やかさと決意を持つ。
- 関係: 狂イ姫（カーティス）の妹。ナーグストールの半身・主人。「セリア」「ニア」は彼女の呼称。
- 引用: 「――セリアック＝ニア。」 / 「楽園の外へ。地下室の外に姉を連れ出せるのなら、たとえ行く先が荒野であっても恐くなど無い。」

### ナーグストール
- 何であるか: セリアック＝ニアの半身であり、宝石細工の猫の姿をした存在。呪文によって形を持ち、涙を流す。
- 関係: セリアック＝ニアと不可分な関係にある。「アンテノル」は本質的な名前だが否定されている。フィリスの下位互換・量産機としての側面を持つ。
- 引用: 「見慣れたシルエットは紛れもなく宝石の獣のものだ。」 / 「ナーグストールはナーグストール。セリアとひとつの――わたしの心」

### 狂イ姫（カーティス）
- 何であるか: セリアック＝ニアの姉であり、吸血鬼の王。男装の麗人としての姿を持つが、邪悪な異獣へと変貌している。
- 関係: セリアック＝ニアの姉。「カーティス」「狂イ姫」は同一人物の呼称。ディスペータを内包している。
- 引用: 「死して英雄となるはずだった聖姫は復活して邪悪な異獣と成り果てた。」 / 「カーティス＝狂イ姫の圧倒的なマジカルアピールの衝撃により吹き飛ばされたセリアック＝ニアだったが」

### 第五階層
- 何であるか: 物語の舞台となるアカシャ間。夜アカシャのような広がりを持ち、俺が拡張身体として存在する場所でもある。
- 関係: 猫たちの集会（サバト）が行われる場所。宝石（キャスケット）が散らばる箱庭的な世界。
- 引用: 「第五階層を拡張身体とした俺が『杖のフィリス』であるナーグストールを使った時」 / 「夜を裂く星の雨、気ままな猫の歌はフェロニア奔放に回り道。」

### 宝石（キャスケット）
- 何であるか: 夜アカシャに散らばる輝き。セリアック＝ニアの祈りが流星となり、世界を縫い合わせる針となるもの。
- 関係: ナーグストールやフィリスと関連する呪文の媒体。「キャスケット」は棺（コフィン）の意味も持つ。
- 引用: 「夜アカシャに浮かんだ宝石たちは流星となって第五階層中に散らばっていった。」 / 「姉妹に裁きをもたらすはずだった宝石の呪いは、いま異なる未来を紡ぎだそうとしている。」

### フィリス
- 何であるか: エル・ア・フィリス。アズーリアが左手に宿している悪戯好きな妖精とは決定的に違う「もう一つのエル・ア・フィリス」。
- 関係: ナーグストールはフィリスの下位互換・複製品として位置づけられている。セリアック＝ニアが操る対抗呪文の一部。
- 引用: 「この妖精を妹姫が扱えることには何の不思議も無い。」 / 「エル・ニア・ナーグストール。もう一つのエル・ア・フィリス」

### 猫たち（アウターゴッズ）
- 何であるか: 異界から飛来した多数の猫。次元を超えた存在であり、世界の常識を崩壊させる力を持つ。
- 関係: セリアック＝ニアの祈りに惹かれて集結し、第五階層で遊戯を行う。俺にもてなされる。
- 引用: 「数え切れないほどの猫の群れ（アウターゴッズ）！」 / 「異邦の神すら戦慄する、理の外を跋扈する宇宙的恐怖。」

### 俺
- 何であるか: 第五階層そのものを拡張身体として存在する存在。ナーグストールを用いて呪文の力をトリシューラに味方させる。
- 関係: 猫たちをもてなし、遊戯を行う。カーティス＝狂イ姫を削ぐ要因の一つ。
- 引用: 「第五階層を拡張身体とした俺が『杖のフィリス』であるナーグストールを使った時」 / 「俺はそれを受けて猫たちを盛大にもてなした。」

### ディスペータ
- 何であるか: 砕けて朽ちた豚の生首。カーティスの心の拠り所であり、セリアック＝ニアの呪的侵入によってカーティスの中に侵入する存在。
- 関係: カーティスの中に存在する。「ディスペータお姉さま」と呼ばれる。
- 引用: 「砕けて朽ちた豚の生首。崩壊する心の拠り所」 / 「セリアック＝ニアの呪的侵入を許してしまっている。」

### (無名)俺（シナモリアキラ）
- 何であるか: 物語の末尾で登場する一人称のシナモリアキラ。舞台監督のような立場で、第五階層での出来事を「初仕事」として完了させる。
- 関係: セリアック＝ニアから宝石を託される。「青い糸」を倒す役目を負う。トリシューラ、コルセスカと行動を共にする。
- 引用: 「俺はそう言って、舞台の上で抱き合う二人の未来を覆い隠すように幕を下ろしていく。」 / 「第五階層となった俺の初仕事はひとまず完了。」

### トリシューラ
- 何であるか: シナモリアキラの傍らにいる人物。忙しそうにしている。
- 関係: 俺が呪文の力を味方させる対象。「青い糸」を倒す戦いに参加する可能性が高い（シナモリアキラが「俺もまた戦わなくてはならない」と述べているため）。
- 引用: 「傍らで忙しそうにしているトリシューラや」 / 「邪視のみならず呪文の力までもがトリシューラに味方する。」

### コルセスカ
- 何であるか: 猫と一緒に踊りながらネズミを追いかけ回している人物。スリッパを投げつけるなどして怪物の正体を暴く役割を果たす。
- 関係: シナモリアキラと同じ現場にいる。虚構の竜（魔竜）の変容に関わる。
- 引用: 「まだ体を動かし足りないのか猫と一緒にフェロニアに踊りながら役目を終えたネズミを追いかけ回しているコルセスカもいる」 / 「コルセスカが夢からスリッパを投げつけた時、怪物の正体は既に暴かれていた。」

### 七つ首のネズミ
- 何であるか: 猫たちの集会に巻き込まれた存在。「ロマンカインドの罪」を試練として掲げていた。
- 関係: 猫たち（アウターゴッズ）に翻弄され、呆然とする。コルセスカに追われる。
- 引用: 「あまりの事態に七つ首のネズミは飛び上がってあたふたとあっちに行ったりこっちに行ったりと忙しなく走り回った。」 / 「大真面目に『ロマンカインドの罪』を試練として掲げていた大きなネズミ」

### ドラトリア
- 何であるか: セリアック＝ニアと狂イ姫の祖国。楽園であり、二人が背を向けた場所。
- 関係: 二人にとっての「故郷」。帰れば石を投げられるという恥曝しの国として描かれる。
- 引用: 「この猫はずっとドラトリアを守ってきた。」 / 「戻れば石を投げられる。帰る故郷はもう失われたのだ。」

### マジカルアピール
- 何であるか: カーティス＝狂イ姫が使う大呪術・パフォーマンス。幻像の再現PVや瘴気を含む。
- 関係: セリアック＝ニアによって対抗される。ドラマ形式であり、形が変われば現実を映し出す。
- 引用: 「カーティスはマジカルアピールに匹敵する幻像の再現PVを瘴気に乗せて送り出した。」 / 「ドラマ形式のマジカルアピールは形が変われば現実すら映し出す。」

### 青い糸
- 何であるか: シナモリアキラが倒すべき対象。セリアック＝ニアを操る力として存在していた可能性がある。
- 関係: シナモリアキラ（俺）が引き継いだ戦いの対象。
- 引用: 「あとは任せて休んでいてくれ。青い糸は俺が倒す」 / 「猫姫は糸の存在に気付きながら、自らを操る力さえ利用して姉を求めたのだ。」

### 聖なるけもの
- 何であるか: セリアック＝ニアの純粋な側面。虚構を生み出す
